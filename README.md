# SpecialTreat Restaurant Website

DCOMP 204 Web Design, Assignment 2: HTML, CSS & Responsive Website
Limkokwing University of Creative Technology, Sierra Leone

Converts the Assignment 1 wireframes (Home, Dishes, Services, About, Contact) into a working responsive website, with Gallery and Testimonials pages added.

## Pages (7)
index.html, dishes.html, services.html, gallery.html, about.html, testimonials.html, contact.html

## Responsive layouts
Mobile-first CSS (`css/style.css`) with breakpoints at 640px (tablet), 800px and 1000px (desktop, where the burger menu becomes a horizontal menu).

## Features
Sticky navigation, hero section, floating WhatsApp button, delivery request form (Address, Food Type, Phone), contact form, Google Map, lazy-loaded images, SEO meta tags and structured data. HTML and CSS only, no JavaScript.
